# 硬件接线

主控: **TI MSPM0G3507** (LQFP-64, Cortex-M0+ @ 32 MHz)
外设配置源: `firmware/board.syscfg` (SysConfig 生成 `ti_msp_dl_config.c/h`)

## 1. 电机驱动 — TB6612

PWM 由 TIMG8 产生, 频率 20 kHz; 速度单位为 % (正=前进)。

| TB6612 信号 | MCU 引脚 | 功能 | 通道 |
| --- | --- | --- | --- |
| PWMA | PB22 (TIMG8 CCP1) | 右轮 PWM | A 通道 = 右轮 |
| AIN1 | PB0 | 右轮方向 1 | |
| AIN2 | PB1 | 右轮方向 2 | |
| PWMB | PB21 (TIMG8 CCP0) | 左轮 PWM | B 通道 = 左轮 |
| BIN1 | PA13 | 左轮方向 1 | |
| BIN2 | PA12 | 左轮方向 2 | |
| STBY | +5V (常使能) | 使能 | |

> 若左右电机实际转向与程序相反, 交换 `drivers/motor_tb6612.c` 中对应方向函数的高低电平即可。

## 2. 灰度循迹传感器 (8 路, 共阴输出, 检测到黑线为低电平)

| 传感器 | MCU 引脚 | 物理位置 | 循迹权重 |
| --- | --- | --- | --- |
| Gray_8 | PB18 | 最左 | −35 |
| Gray_7 | PA14 | 左偏 | −25 |
| Gray_6 | PB20 | 左偏 | −15 |
| Gray_5 | PB24 | 左中 | −5 |
| Gray_4 | PB25 | 右中 | +5 |
| Gray_3 | PA24 | 右偏 | +15 |
| Gray_2 | PB19 | 右偏 | +25 |
| Gray_1 | PA30 | 最右 | +35 |

> 若模块输出极性相反, 在 `drivers/line_tracker.c` 的 `sensorActive` 中反转判断。

## 3. 双轮编码器 (A/B 相, 仅上升沿 2 倍频计程)

| 编码器 | A 相 | B 相 | 所属 GPIO |
| --- | --- | --- | --- |
| 右轮 | PA16 | PA15 | GPIOA |
| 左轮 | PB09 | PB08 | GPIOB |

- 13 PPR × 28 (减速比) × 2 (倍频) = **728 计数/轮**
- 轮周长 π × 65 mm ≈ 204.2 mm → 分辨率 ≈ **0.28 mm/计数**
- MSPM0 的 GPIOA/GPIOB 共用 GROUP1 中断, 由 `drivers/encoder_odometry.c` 独占
- 不判别方向, 倒车时里程仍正向累加

## 4. 摆杆执行 — Emm_V5 闭环步进电机 (UART2)

| 信号 | MCU 引脚 | 说明 |
| --- | --- | --- |
| UART2_TX | PB15 | → 驱动器 RX |
| UART2_RX | PB16 | ← 驱动器 TX |

- 115200 8N1, 电机地址默认 1
- 位置模式: 300 RPM, 加速度档位 50; 每个 5 ms 控制周期最大步进 0.2° (换向 0.35°)
- 软件安全限幅 ±30°; 上电时电机须人工置于机械零位

## 5. 钢球视觉 — MaixCAM2 (UART3)

| 信号 | MCU 引脚 | 说明 |
| --- | --- | --- |
| UART3_TX | PB6 | → 相机 RX (可不接) |
| UART3_RX | PB7 | ← 相机 TX (坐标回传) |

- 115200 8N1, RX 中断优先级 0 (最高)
- 协议: `#±xx.xx!` (cm, 范围 ±12.5) / `#N!` (丢球)
- 相机端代码见 `vision/`, 摄像头固定于摆杆凹槽正上方, 画面覆盖整根摆杆

## 6. 显示屏 — 0.96" OLED (I2C, 软件模拟)

| 信号 | MCU 引脚 |
| --- | --- |
| SCL | PA31 |
| SDA | PA28 |

- 128×64, 显示模式名 / Yaw / 球位置 / 速度 / PID 参数 / 计时
- 刷新周期 100 ms

## 7. 按键 (内部上拉, 低电平有效)

| 按键 | MCU 引脚 | 功能 |
| --- | --- | --- |
| S1 | PA25 | 启动 / 停止当前模式 |
| S2 | PA26 | 循环切换模式 |
| S3 | PB23 | 调参 + (Kp / 距离微调 +0.5 cm) |
| S4 | PA29 | 调参 − (Kp / 距离微调 −0.5 cm) |

## 8. 其他接口

| 接口 | 引脚 | 状态 |

| ESP32 图传 (UART0) | PA10 (TX) / PA11 (RX) | `drivers/esp32_camera_link.c`, 上电自动配置 AP 热点 |
